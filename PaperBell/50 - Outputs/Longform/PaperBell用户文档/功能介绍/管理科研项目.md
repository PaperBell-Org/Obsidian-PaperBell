> [!quote]
> 项目管理，我们帮你整理。

[[科研项目]]是 [[CIMPO]] 里最顶级的管理层：它通常以年计（半年以上，单篇论文不算），用一个稳定的主页把与之关联的想法、文献、笔记、待办、[[输出系统|输出]]集中展示出来。

## 追踪项目

`PaperBell` 的项目管理完全由 Obsidian 原生的 **Bases** 驱动，不再依赖任何单独的项目插件。主页的 「**Project Tracking**」会嵌入 `00. 项目列表.base`，并根据每个项目里[里程碑待办](#里程碑)的完成情况自动生成进度条。

![[追踪项目.gif]]

项目用标签识别：给**任意地方**的笔记或待办加上 `#project/<项目ID>`（如 `#project/PaperBell`），它就会被该项目收录。每个项目主页底部都嵌入了 `项目检索.base`，自动汇总所有带本项目标签的笔记——输入资料、输出笔记、零散待办，一览无余。

而在项目列表 `00. 项目列表.base` 里，你可以用不同视图纵览全部项目：

- **项目概览**：卡片墙，按状态分组，显示封面与任务进度；
- **详细列表**：表格，含状态、阶段、起止、负责人、资金数量等；
- **进行中 / 已完成**：按优先级或结束时间筛选；
- **项目产出**：汇总各项目名下的 Longform 手稿（`50 - Outputs` 里的 Index）；
- **甘特图 / 项目视图**：由 `Task Genius` 提供，把项目与其里程碑待办画成时间线。

## 里程碑

每个项目主页的 `## 🙋 Milestones` 区块下，里程碑就是**普通的 Markdown 待办**：

```markdown
- [x] v1 框架搭建 📅 2023-09-01
- [ ] v2 学者追踪
```

这样做的最大好处是**不依赖任何单独内嵌的前端组件**——勾选 `- [ ]` / `- [x]` 即可维护。`Task Genius`（任务进度条插件）会自动在标题旁渲染完成进度，`00. 项目列表.base` 的「任务进度」列也会据此统计。需要跨项目纵览所有待办时，打开 `01. 任务总览.base`。

> [!tip]
> 想给里程碑加日期，用 `📅 YYYY-MM-DD`；想把任意笔记里的某条待办归到某个项目，给那一行加上 `#project/<项目ID>` 标签即可（它会出现在 `01. 任务总览.base` 里）。

> [!info]
> 从 5.x 起，项目里程碑已从早先内嵌的时间线组件（一个 React 前端），重构为上面这种原生 Markdown 待办——更易维护、零额外依赖。

## 新建项目

新建项目最简单的方式是用 `QuickAdd`：`Command(Ctrl) + P` 唤出命令面板，运行 **【添加学术项目】**。`PaperBell` 会套用 `项目模板`（Templater）依次提示你填写：

1. **类型**：研究 / 软件 / 管理；
2. **工作量**（1–5）、**负责人 (PI)**、**你的角色**（负责人 / 项目骨干 / 参与者）、**阶段**（探索期 / 执行期 / 维护期 / 结题期）、**优先级**；
3. **项目缩写 (ID)**：必填且唯一——模板会用它自动重命名文件，并在 ID 重复时拒绝创建；
4. **全称、关联项目、围绕的[[概念卡|概念]]、简介**。

创建后你会得到一个项目主页，里面已经备好 `## 🙋 Milestones`、参与者、导航，以及 `项目检索.base`。接下来你只需要：

- 在 `## 🙋 Milestones` 下用 `- [ ]` 维护里程碑；
- 把项目相关的待办、笔记加上 `#project/<ID>` 标签；
- 按需补全 `url`、`grants`（资金）、`participants`（参与者，wikilink 到学者）等属性。

> [!tip]
> 想给项目加一个"一键打开"的深链接，可以用 `Advanced URI: copy URI for command` 复制命令链接，粘贴到项目的 `url` 字段。
