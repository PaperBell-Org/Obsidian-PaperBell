> [!quote]
> 读不完的文献、写不完的论文,都在往前推着你的学术生涯——你需要一块能一眼看清「自己走到哪了」的面板。

`PaperBell Section` 是 PaperBell 套件里的**仪表盘插件**。在 [[核心设计理念|CIMPO]] 五层里,它站在 **Metadata(元数据)层**上,把「人 / 时」这类关于**你这位学者本人**的元数据——个人资料、每天与每周的活动、写作字数的长期轨迹、研究方向的变化——汇成一块可视化的**生涯进展**面板。

> [!note]
> 其它 PaperBell 专属插件各管一层(制概念卡、归一化输入、渲染项目卡、编译手稿),而 Section 不耕作某一层,只做**总览**:阅读([[文献阅读笔记|输入]])和写作([[撰写输出笔记|输出]])在这里都作为「活动信号」,汇入你的生涯轴。

## 怎么打开

三种方式任选:

- 点左侧边栏的 **仪表盘图标**(`layout-dashboard`);
- `Command(Ctrl) + P` 打开命令面板,搜 **Open PaperBell Section**;
- 在 PaperBell 主插件的设置页,「已接入的插件」里点 **PaperBell Section** 入口卡片。

打开后是一个占据整个标签页的面板:顶部是**个人资料页眉**,下面是**学术 / 项目 / 个人**三个标签页。

## 学术标签页:你的生涯主视图

- **学术概览**:一条本月对比上月的**累计写作字数**曲线,加上总字数、月度增长,以及文献 / 笔记 / 草稿 / 已发表四块统计。
- **今日聚焦 · 周表现**:今天、以及本周对比上周的笔记时长、写作字数、文献笔记数。「灵感」一栏来自你**当天的日记**里记录的条目。
- **最近文献 · 研究焦点**:最近读的文献,以及一张**研究方向热力图 / 网格**——用你关注的研究标签,展示关注点如何随周次演进。点格子还能下钻看那段时间的具体笔记。

> [!tip]
> 「草稿 / 已发表」是根据**论文文件夹**里笔记的 `status` 字段数出来的;「文献」数则看**文献文件夹**。这两个文件夹在插件设置里配置(见下)。

## 项目 / 个人标签页

- **项目**:研究论文 / 实验数据 / 科研课题 / 学术资源四张卡片,每张展示你指定的一个 `.base` 文件——第一次用点卡片上的按钮选一个即可。
- **个人**:选一个文件夹当**书架**,插件会自动生成一个画廊视图展示藏书。

## 番茄钟

状态栏里有一个**专注计时器**:左键开始 / 暂停,右键可暂停 / 跳过 / 停止,并显示「今日完成 N 次」。也可以在「周表现」面板点 **Start focus** 启动。时长与休息规则都能在设置里改。

## 在设置里配置

打开插件设置,分五组:

- **个人资料**:显示在页眉的姓名 / 身份 / 邮箱 / 机构 / 头像。
- **数据来源**:**论文文件夹**(统计论文/草稿/发表)、**文献文件夹**(统计文献)、**书籍文件夹**,以及**研究标签**(英文逗号分隔,决定研究焦点热力图追踪哪些方向)与热力图的格子大小 / 圆角。
- **Base 文件 · 组件文案 · 专注计时**:分别配置各卡片对应的 `.base` 路径、每个组件的标题文案、以及番茄钟时长与自动化开关。

> [!tip]
> 如果你用的是 PaperBell 示例库,记得把「论文文件夹 / 文献文件夹」指向你实际的 `50 - Outputs` / `20 - Inputs/Zotero` 等路径,统计才准确。

## 它和其它功能的关系

Section 目前**只读你自己的仓库约定**(文件夹、`status` 字段、标签、当日日记),不依赖其它插件也能独立工作;它呈现的「学者」目前聚焦在**你本人**。想把视野扩展到[[追踪学者和组织|你追踪的其他学者]]、机构与资助,是这块面板未来的生长方向。
