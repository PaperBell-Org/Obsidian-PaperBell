这是[[输出系统]]的最后一步：把[[撰写长文本|长文本]]编译出的 `.md` 手稿，一键变成可投稿的 PDF / Word。

## 理论基础

当需要将 `MarkDown` 格式的笔记转化为其它格式时，底层有两条路线：

1. 将 `MarkDown` 笔记转化为 `LaTeX` 格式，再转化为其它格式
2. 将 `MarkDown` 笔记转化为 `HTML` 格式，再转化为其它格式

`PaperBell` 主要使用 [Pandoc](https://pandoc.org/) 作为底层工具，并使用 `LaTeX` 作为中转格式（路线1）。所以，你需要[确保 Pandoc 和与之适配的 LaTeX 已经安装](https://pandoc.org/installing.html)。

## 使用方法

导出由 **PaperOut To-Authors**（插件 id `longform-paperbell`）负责。它把长文本的「编译（Compile）」和 Pandoc 导出串成一条工作流：你在 Longform 面板里组织场景，选一个工作流，点一次按钮就得到成品。

内置四条工作流，对应投稿时最常用的四类文件：

| 工作流 | 用途 | Pandoc 预设 |
| --- | --- | --- |
| `PaperBell Manuscript` | 正文手稿 | `defaults/paperbell.yaml` |
| `PaperBell Supplementary` | 补充材料（SI） | `defaults/paperbell.yaml` |
| `PaperBell Response Letter` | 返修回复信 | `defaults/response-letter.yaml` |
| `PaperBell Cover Letter` | 投稿信 | `defaults/cover_letter.yaml` |

使用步骤：

1. 在左侧 **Longform** 面板中选中你的项目（示例项目为 `50 - Outputs/Longform/paper-demo`）
2. 切换到 **Compile** 选项卡
3. 在工作流下拉框中选择上表中的一条
4. 点击 **Compile**，产物会输出到插件设置中的 `pandocOutputFolder`

Pandoc 资产（模板、CSL 样式、Lua 过滤器）统一存放在 `00 - Obsidian/pandoc/`，由插件从资产市场下载并管理，无需手工配置。

## 修改模板

通常情况下，用户可以直接在 YAML 头文件中对常用的参数进行设置，目前可以修改的变量包括：

- 文档标题: `title`
- 日期: `date`

对于想要订制模板的用户，可以参考 [[笔记导出模板]] 中的说明。

## 投稿与版本管理

导出只是投稿流程的一环。返修时用 `PaperBell Response Letter` 生成回复信，投稿时用 `PaperBell Cover Letter` 生成投稿信；手稿本身的版本管理建议直接用 Git 管理仓库。
