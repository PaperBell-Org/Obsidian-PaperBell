聚沙成塔，`PaperBell` 感谢这些出色的开源插件，让本仓库的工作流得以丝滑实现。

### PaperBell 自有插件

这几个插件由 PaperBell 开发，随示例库一起分发，是 CIMPO 工作流的骨架。

| 插件 id | 显示名 | 简单介绍 | 重要性 |
| --- | --- | --- | --- |
| **paperbell** | PaperBell | 学术写作工作流总控，管理机构笔记与学者档案。 | ⭐⭐⭐ |
| **longform-paperbell** | PaperOut To-Authors | 长文本项目管理 + Pandoc 导出（手稿／补充材料／回复信／投稿信）。 | ⭐⭐⭐ |
| **paperbell-cards-wrangler** | PaperBell Cards Wrangler | 从输入笔记自动生长概念卡与关键词，托管 `10 - Cards` 层。 | ⭐⭐⭐ |
| **paperbell-project-manager** | PaperBell Project Manager | 在 Bases 里把项目渲染成卡片：身份、阶段、里程碑进度、资助与交付物反查。 | ⭐⭐⭐ |
| **paper-in-bell** | Inputs Bell | 输入文件夹的后处理钩子：规范 frontmatter、本地化图片、校验 Zotero、按字段归档。 | ⭐⭐⭐ |
| **papersearch** | PaperSearch | 检索、阅读与标注文献，写作时保留可追溯来源。 | ⭐⭐ |
| **paperbell-section** | PaperBell Section | 独立的 PaperBell 工作区视图。 | ⭐ |

### 社区插件

| 插件 id | 显示名 | 简单介绍 | 重要性 |
| --- | --- | --- | --- |
| **zotlit** | ZotLit | 集成 Zotero，管理文献笔记和引用。 | ⭐⭐⭐ |
| **templater-obsidian** | Templater | 模板引擎，驱动各类笔记的自动创建。 | ⭐⭐⭐ |
| **quickadd** | QuickAdd | 提供快速添加笔记、任务的功能。 | ⭐⭐⭐ |
| **obsidian-task-progress-bar** | Task Genius | 任务管理与进度条，支撑项目里程碑与任务总览视图。 | ⭐⭐⭐ |
| **dataview** | Dataview | 数据查询与显示。仅用于 Bases 无法表达的两处：概念卡「相关想法」与基金「交付义务」。 | ⭐⭐ |
| **obsidian-memos** | Thino | 快速创建和管理备忘录，适合轻量级记录。 | ⭐⭐ |
| **obsidian-map-view** | Map View | 提供地图视图，将笔记中的地理信息可视化。 | ⭐⭐ |
| **pexels-banner** | Pixel Banner | 在笔记顶部添加自定义横幅图片。 | ⭐⭐ |
| **obsidian-advanced-uri** | Advanced URI | 提供可跳转到指定笔记／命令的 URI，主页导航依赖它。 | ⭐⭐ |
| **realclaudian** | Claudian | 把 Claude Code 等编程智能体嵌入库中作为 AI 协作者。 | ⭐ |
| **calendar** | Calendar | 添加日历视图，管理时间线。 | ⭐ |
| **cm-chs-patch** | Simplified Chinese Word Splitting | 提供中文分词支持。 | ⭐ |
| **homepage** | Homepage | 设置自定义首页，快速访问常用笔记。 | ⭐ |
| **obsidian-admonition** | Admonition | 创建带样式的警告框、提示框等。 | ⭐ |
| **floating-toc** | floating toc | 在文档左侧呈现可快速跳转的目录。 | ⭐ |
| **obsidian-hover-editor** | Hover Editor | 悬停时编辑链接预览。 | ⭐ |
| **obsidian-minimal-settings** | Minimal Theme Settings | 支持 Minimal 主题的配置。 | ⭐ |
| **obsidian-style-settings** | Style Settings | 提供界面样式的详细设置。 | ⭐ |
| **obsidian-sortable** | Sortable | 让表格支持点击表头排序。 | ⭐ |
| **recent-files-obsidian** | Recent Files | 管理最近打开的文件。 | ⭐ |
| **tag-wrangler** | Tag Wrangler | 管理和组织标签。 | ⭐ |
| **soundscapes** | Soundscapes | 写作时播放白噪音／环境音。 | ⭐ |
| **obsidian42-brat** | BRAT | 安装并更新以 beta 形式发布的插件。上表「PaperBell 自有插件」全部经由它分发，示例库已随附，请勿停用。 | ⭐⭐⭐ |

> [!note]
> ⭐⭐⭐ 核心插件：PaperBell 的核心功能依赖这些插件
> ⭐⭐ 重要插件：提供重要的辅助功能
> ⭐ 可选插件：提供额外的便利性功能

> [!tip] 视图层已迁移到 Bases
> 早期版本用 Dataview 渲染各种列表，现在绝大多数视图都改为 Obsidian 原生的 **Bases**（`.base` 文件），
> 例如 `00. 概念墙.base`、`00. 项目列表.base`、`00. 资助总览.base`。
> Dataview 仅保留在 Bases 结构上无法表达的两处：概念卡的「相关想法」（按行检索 `#想法`）
> 与基金笔记的「交付义务」（跨文件汇总带 `#grant/<slug>` 的任务）。
