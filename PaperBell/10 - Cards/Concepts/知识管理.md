## Description
> [!seealso]+ Source
> 💡 **本概念由 [[卡片盒笔记法与知识的涌现]] 笔记创建而来**

> [!note] Definition
>
> **知识管理（knowledge management）** 研究如何系统地捕获、组织、连接与复用知识。落到个人科研场景，就是**个人知识管理（PKM）**：把读过的[[关键词|材料]]、闪过的想法、写下的[[输出系统|输出]]编织成一张可检索、可生长的网络——这正是 [[CIMPO]] 方法论想解决的问题。

    }
    return null;
});

Promise.all(arr).then(values => {
    const filteredValues = values.filter(value => value != null);

    });
    const exists = beautify.filter(value => value[1][0])
        .sort((a, b) => a[0].localeCompare(b[0]));
